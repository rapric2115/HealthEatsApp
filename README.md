# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
    npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Get a fresh project

# Project Information

Help users make informed food choices by generating personalized meals, explaining their nutritional value, and adapting recommendations to their health goals, dietary needs, tastes, budget, and lifestyle.
The app should answer five important questions for every user:
- What should I eat based on my needs?
- Why is this meal a good choice for me?
- What ingredients do I need, and how do I prepare it?
- How does this meal contribute to my daily nutritional goals?
- How can I eat healthier without giving up the foods I love?

# The Main features to include
## Personalized health profile
- Users enter their age, height, weight, activity level, dietary preferences, allergies, health goals, and relevant health conditions. The app uses these details to personalize meal recommendations.
## AI-powered meal generator
- Gemini creates meals from the user's profile and preferences, with ingredients, quantities, cooking instructions, preparation time, serving sizes, estimated nutritional values, and personalized explanations.
## Nutrition education
- Explain protein, carbohydrates, fats, fiber, vitamins, minerals, hydration, portion sizes, and how these contribute to general health. Help users understand the reasons behind recommendations instead of simply telling them what to eat.
## Weekly meal planner
- Generate breakfast, lunch, dinner, and snack suggestions for the week. Let users swap meals, reuse leftovers, adjust portions, and build a grocery list from the plan.
## Smart grocery assistant
- Combine ingredients across selected recipes, group them by category, adjust quantities by servings, and help users find budget-friendly alternatives or use ingredients they already have.
## Food diary and progress
- Allow users to record meals, review estimated nutritional intake, track consistency with their goals, and notice eating patterns over time. Focus on positive habits rather than guilt or punishment.
